# 本棚（蔵書管理アプリ）

持っている本を記録し、一覧で確認するための個人用 Web アプリです。
iPhone の Safari で開き、「ホーム画面に追加」して使います。

## できること

- ISBN バーコードを読み取り、題名・よみがな・作者・出版社を自動取得（NDLサーチ API）
- バーコードの無い本や書誌が見つからない本の手入力登録、登録後の修正
- 表紙などの写真の保存（保存時に自動で縮小・圧縮）と閲覧
- 題名の一覧表示、題名を押すと詳細ページへ移動
- 並べ替え：五十音順／ジャンル別／好きな順（ドラッグ）／登録順
- 題名・作者・出版社での検索
- 登録済みの本の重複チェック
- 読書状態（未読・読書中・読了）、メモ、巻数
- シリーズ：自分で名前を付けて作成し、入れる本を選んでまとめる
- ジャンルの追加・名前変更・削除
- バックアップの書き出し・読み込み

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリの土台。各ファイルを読み込む |
| `css/style.css` | 見た目 |
| `js/app.js` | アプリ本体（画面の表示と操作） |
| `js/db.js` | データの保存と読み出し（IndexedDB） |
| `js/ndl.js` | NDLサーチ API での書誌取得 |
| `js/scanner.js` | カメラでのバーコード読み取り |
| `js/image.js` | 写真の縮小・圧縮 |
| `js/backup.js` | バックアップの書き出し・読み込み |
| `js/util.js` | 共通の小さな関数 |
| `lib/zxing.min.js` | バーコード読み取りライブラリ ZXing（Apache License 2.0） |
| `sw.js` | 電波が無くてもアプリを開けるようにする仕組み |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |
| `proxy/ndl-proxy.gs` | NDLサーチへの中継プログラム（必要な場合のみ使用） |

## パソコンで試す

このフォルダでコマンドプロンプトを開き、次を実行します。

```
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。
パソコンにカメラがあればバーコード読み取りも試せます。

## iPhone で使う

カメラは `https://` のページでしか使えないため、インターネット上に置く必要があります。
無料の GitHub Pages を使う場合の流れは次の通りです。

1. GitHub で新しいリポジトリを作る
2. このフォルダの中身（`index.html` が一番上の階層に来るように）をアップロードする
3. リポジトリの Settings → Pages で、公開元のブランチを選んで保存する
4. 表示された `https://ユーザー名.github.io/リポジトリ名/` を iPhone の Safari で開く
5. 共有ボタン →「ホーム画面に追加」

公開されるのはアプリのプログラムだけです。
本のデータと写真は iPhone の中にだけ保存され、他の人からは見えません。

## 中継プログラムの設置（必要な場合のみ）

ブラウザの安全上の決まり（CORS）により、アプリから NDLサーチへ直接問い合わせても
結果を読めない場合があります。「書誌を検索」が毎回
「NDLサーチに接続できませんでした」になる場合は、次の手順で中継プログラムを用意します。
Google アカウントがあれば無料で作れます。

1. https://script.google.com/ を開き、「新しいプロジェクト」を作る
2. 最初から入っているコードを消し、`proxy/ndl-proxy.gs` の中身を貼り付けて保存する
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」を選ぶ
4. 「次のユーザーとして実行」は「自分」、「アクセスできるユーザー」は「全員」にしてデプロイする
5. 表示された URL（`https://script.google.com/macros/s/…/exec`）をコピーする
6. 本棚アプリの「設定」→「書誌検索」→「中継URL」に貼り付けて保存する

## 使うときの注意

- データは端末のブラウザ内に保存されます。Safari の「履歴とWebサイトデータを消去」を行うと消えます。
  設定画面から定期的にバックアップを書き出してください。
- Safari のプライベートブラウズでは使えません。
- Safari で開いた場合と、ホーム画面から開いた場合とでは、データの保存場所が別になることがあります。
  ホーム画面に追加してから登録を始めてください。

## クレジット

このアプリは、書誌情報の取得に国立国会図書館サーチ（NDLサーチ）の API を利用しています。
